# NiftyMind

An AI-powered financial intelligence and investment analysis platform for retail stock investors.

---

## What is NiftyMind?

NiftyMind analyzes stocks using a team of specialized AI agents working together in real time. Instead of relying on a single metric, it cross-examines technical indicators, regulatory audit reports, and breaking news to give clear, balanced investment insights tailored to your personal risk tolerance.

---

## Key Features

- **3 Parallel AI Detectives**:
  - **Chart Detective**: Analyzes price action, moving averages (EMA), RSI momentum, and volume trends.
  - **Rulebook Detective**: Scans corporate audit reports, regulatory disclosures, and governance red flags.
  - **News & Sentiment Detective**: Evaluates breaking headlines and public sentiment to filter market noise.

- **Boss AI Synthesizer**: Resolves conflicts between signals and gives a final, clear verdict (Bullish, Bearish, or Neutral) with a confidence score.

- **Risk Profile Customization**: Adjust recommendations based on whether you are a **Conservative**, **Moderate**, or **Aggressive** investor.

- **Interactive Price Charts**: Clean technical charts with candlestick/line views, volume bars, EMA overlays, and RSI indicators.

- **Live Market Data**: Real-time equity prices, day ranges, and volume tracking.

- **Google Trends Radar**: Track search interest momentum and retail investor attention for any stock.

- **Portfolio Health Audit**: Scan your entire portfolio to check for risk concentration and balance.

- **Interactive AI Chat**: Chat directly with any individual detective or the Boss AI to ask questions about why an analysis was made.

- **Custom Alerts**: Get notified about trend reversals, price target breaches, and forensic warning flags.

## Quick Start

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Add your Gemini API Key to `.env`:**
   ```env
   GEMINI_API_KEY="your_api_key_here"
   ```

3. **Start the app:**
   ```bash
   npm run dev
   ```
